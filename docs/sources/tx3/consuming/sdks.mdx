A Tx3 SDK is the runtime library your application uses to consume a Tx3 protocol. It provides the TRP transport, party and signer bindings, and the four-stage transaction lifecycle: `resolve → sign → submit → wait`.

A client produced by [`trix codegen`](/tx3/consuming/codegen) is a thin typed layer on top of this SDK — it delegates to the SDK for everything but the typed transaction methods. You can also use the SDK directly without codegen; see [Dynamic Usage](/tx3/consuming/dynamic-usage).

The conceptual surface is identical across every supported language; only the syntax differs. For a step-by-step walkthrough in your language of choice, see the [Quick Start](/tx3/consuming/quick-start).

This page is a directory: each supported language, where its source lives, and where to install it from.

## TypeScript

The TypeScript SDK targets Node.js, modern browsers, Bun, and Deno. It ships CIP-30 wallet bridges and bundler plugins (Vite, Rollup, Next.js) so consumers can generate clients at build time instead of committing them.

- **Source:** [`tx3-lang/web-sdk`](https://github.com/tx3-lang/web-sdk)
- **Package:** [`tx3-sdk` on npm](https://www.npmjs.com/package/tx3-sdk)
- **Install:** `npm install tx3-sdk`

## Rust

The Rust SDK is the canonical reference implementation. Cargo features gate optional integrations; a low-level TRP client and custom signer hooks are exposed for callers that need to bypass the high-level builder.

- **Source:** [`tx3-lang/rust-sdk`](https://github.com/tx3-lang/rust-sdk)
- **Package:** [`tx3-sdk` on crates.io](https://crates.io/crates/tx3-sdk)
- **Install:** `cargo add tx3-sdk`

## Go

The Go SDK exposes typed errors, a context-aware lifecycle, and a low-level TRP client for backends that need to integrate without the full builder surface.

- **Source:** [`tx3-lang/go-sdk`](https://github.com/tx3-lang/go-sdk)
- **Package:** [`github.com/tx3-lang/go-sdk/sdk` on pkg.go.dev](https://pkg.go.dev/github.com/tx3-lang/go-sdk/sdk)
- **Install:** `go get github.com/tx3-lang/go-sdk/sdk`

## Python

The Python SDK exposes an async lifecycle, a low-level TRP client, and custom signer hooks.

- **Source:** [`tx3-lang/python-sdk`](https://github.com/tx3-lang/python-sdk)
- **Package:** [`tx3-sdk` on PyPI](https://pypi.org/project/tx3-sdk/)
- **Install:** `pip install tx3-sdk`

## Java

The Java SDK targets Java 21 on macOS, Linux, and Windows. Its lifecycle returns cancellable `CompletableFuture`s, failures are typed unchecked `Tx3Exception`s, and a low-level TRP client is exposed for callers that bypass the builder. Kotlin and other JVM languages consume it as an ordinary dependency.

- **Source:** [`tx3-lang/java-sdk`](https://github.com/tx3-lang/java-sdk)
- **Package:** [`land.tx3:tx3-sdk` on Maven Central](https://central.sonatype.com/artifact/land.tx3/tx3-sdk)
- **Install:** add the `land.tx3:tx3-sdk` dependency to your `pom.xml` or Gradle build

## Swift

The Swift SDK targets macOS 14+ and iOS 18+ (Swift 6.1 / Xcode 16.4). It uses native `async`/`await` with cancellation, typed `Tx3Error` cases, and is distributed as a SwiftPM source package.

- **Source:** [`tx3-lang/swift-sdk`](https://github.com/tx3-lang/swift-sdk)
- **Package:** [`Tx3SDK` on GitHub](https://github.com/tx3-lang/swift-sdk/releases)
- **Install:** `.package(url: "https://github.com/tx3-lang/swift-sdk", from: "0.15.0")` in `Package.swift`
